<h1>Objetivo</h1>
<p>Desenvolver um sistema de xadrez em Java no qual é possível duas pessoas jogarem xadrez através de comando no teclado.</p>

<h1>Requerimentos</h1>
<p>Ter um prompt de comando com suporte a cores.</p>

<h1>Como usar</h1>
<p>Baixe o projeto;</p>
<p>Vá até a pasta ‘bin’ do projeto;</p>
<p>Com um prompt de comando aberto digite o comando “java application/Program”.</p>
